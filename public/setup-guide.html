← Install Second Mind

Setup, explained.

What gets installed?

Second Mind installs for your Windows user under %LOCALAPPDATA%\SecondMind. If compatible Node.js 24 is missing, setup downloads a private runtime from nodejs.org. It verifies the runtime checksum and the app’s published SHA-256 checksum before installation. App dependencies are downloaded from the npm registry.

A secondmind command is added to your user PATH. No administrator permissions or Windows service are required.

First run

The browser opens automatically. Choose a knowledge folder or prepare the English model first. That model download is cached on your computer. Subsequent local indexing and searches work offline.

Starting and stopping

Run secondmind in a terminal. Keep that terminal open. Closing the browser does not stop indexing. Press Ctrl+C or run secondmind stop to stop the service and its tunnel.

Updating

Stop Second Mind, then run the same install command. Original documents are never changed. Your app data remains in place. Earlier installed app versions are retained so a failed download does not remove your previous installation.

Remote connections

Remote access is optional and off by default. Install Cloudflare’s cloudflared executable, create a named tunnel and hostname in your own Cloudflare account, then configure its token in Second Mind. Retrieved excerpts travel through Cloudflare to an authorized AI client. The knowledge index remains local.

Removing the app

Stop Second Mind. Remove its bin directory from your user PATH, then delete its application folder if you also want to delete the local models, credentials, and derived index. This never requires deleting your original knowledge folders.
